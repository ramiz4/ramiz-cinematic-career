# Ramiz Cinematic Career

A production-oriented React 19, TypeScript and React Three Fiber career experience.

## Development

```bash
npm install
npm run dev
```

## Quality gates

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

GitHub Actions validates every push and pull request. Successful pushes to `main` are deployed to GitHub Pages.
